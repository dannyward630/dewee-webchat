Use your own gateway

Point the widget at your own Dewee gateway. The URL and key travel with each request through this demo's Worker and are never stored. Use a scoped operator API key, not an admin token. This direct-gateway mode is deprecated; real sites use a CCP Website chat integration.

Why there is a backend

Your integration secret identifies your site to Dewee. It must never reach a browser.

Dewee CCPWebsite chat integrationagents, sign-in and limits
  • Secret stays server-side. The browser gets an HMAC-signed visitor id, nothing else.
  • Visitors are isolated. Each one gets its own visitor identity at Dewee; history is scoped to them.
  • Agent allowlist. Only the agents the integration allows can be reached, whatever the client asks for.
  • Abuse limits. Origin allowlist, per-visitor rate limits, message length cap, optional Turnstile.
